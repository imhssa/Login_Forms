# Blue Login Form

A clean blue-themed login form built with HTML and CSS, featuring a simple and focused authentication interface.

## Features
- Blue-themed UI
- Clean login form
- Responsive layout
- Image-based visual element
- Simple and reusable structure

## Technologies
- HTML5
- CSS3
