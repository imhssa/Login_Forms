# Login Forms

A collection of login-form designs built with HTML and CSS. Each folder is a separate version with a different visual style.

## Projects

- [Blob Login Form](LoginForm-Blob/) — a blob-style layout with social icons
- [Blue Login Form](LoginForm-Blue/) — a simple blue design
- [Gray Login Form](LoginForm-Gray/) — a minimal gray version
- [Green Login Form](LoginForm-Green/) — a green design with a background image

## Built With

- HTML5
- CSS3
