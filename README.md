# Login Forms Collection

A collection of **login form UI projects** built with **HTML5 and CSS3**. Each project is organized in its own folder and explores a different visual style for a login interface.

## Projects

| Project | Description | Live Demo |
|---|---|---|
| [Blob Login Form](LoginForm-Blob/) | Modern blob-style login interface with social icons | [Live Demo](https://imhssa.github.io/Login_Forms/LoginForm-Blob/) |
| [Blue Login Form](LoginForm-Blue/) | Clean blue-themed login form | [Live Demo](https://imhssa.github.io/Login_Forms/LoginForm-Blue/) |
| [Gray Login Form](LoginForm-Gray/) | Minimal gray login interface | [Live Demo](https://imhssa.github.io/Login_Forms/LoginForm-Gray/) |
| [Green Login Form](LoginForm-Green/) | Green-themed login form with a visual background | [Live Demo](https://imhssa.github.io/Login_Forms/LoginForm-Green/) |

## Technologies
- HTML5
- CSS3

These projects are built without JavaScript frameworks or CSS frameworks.

## About This Repository
Each folder is an independent frontend project. The collection demonstrates different approaches to login-form composition, color themes, visual assets, spacing, and CSS styling.

Every project README includes:
- Project overview
- Features
- Technologies used
- Folder structure
- Live demo
- Project purpose
