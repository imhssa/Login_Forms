# Blob Login Form

A modern login form with a distinctive blob-style visual design, built with HTML and CSS.

## Features
- Modern login interface
- Blob-inspired visual element
- Social login icons
- Clean form layout
- Responsive styling

## Technologies
- HTML5
- CSS3
